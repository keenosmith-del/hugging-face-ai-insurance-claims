# Synthetic evidence

claim-001 contains fictional policy, accident report and estimate text, a rasterised report (PNG/PDF), a drawn vehicle schematic, and a generated synthetic accident photograph. synthetic-accident.png carries a visible SYNTHETIC DEMO IMAGE label, fictional DEMO123 registration and no real customer identity. Generated using the built-in imagegen tool; this is an input fixture, never an AI prediction.

Generation prompt: realistic daylight documentary-style photograph of a fictional unbranded silver sedan on a quiet fictional road after a minor low-speed collision, modest front-bumper dent and cracked left headlight; entire car visible from front three-quarter view; no people, injuries, brands or identifiable houses; plate DEMO123; visible top caption SYNTHETIC DEMO IMAGE.

Upload the PDF version of the report for OCR. Omit policy/estimate for an incomplete case, or change a labelled Registration to DEMO999 for a discrepancy case. Model outputs are not hardcoded. The photograph is a smoke-test input, not an accuracy benchmark or proof of real damage. The drawn schematic remains an optional challenging input that may return no detections.
